
# YAMA OBJECT VISION AI

**Version:** 1.0  
**Project:** YAMA AI  
**Purpose:** AI Object Detection and Visual Search

## 1. Introduction

YAMA Object Vision AI is an AI-powered
object recognition project designed to
work with an iPhone camera.

## 2. Main Features

- Real-time camera access
- Object detection
- Multiple object recognition
- Object confidence scoring
- Object tracking (future development)
- Visual search (future development)
- Vietnamese, Japanese and English support (planned)

## 3. Technologies

- Python
- YOLOv8
- OpenCV
- JavaScript
- HTML
- CSS
- Google Colab
- GitHub

Install dependencies:

